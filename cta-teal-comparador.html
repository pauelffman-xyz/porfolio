Comparador de legibilidad · "VIEW CASE STUDY"

Cuatro tratamientos sobre tus tres fondos reales. El actual pierde contraste porque el gradiente cae a teal oscuro (#005043) justo donde el fondo ya es casi negro. Cambiá el fondo y comparalos.

01 · Actual

Actual — gradiente que cae

El extremo #005043 se apaga sobre fondo oscuro. Este es el problema.

background:linear-gradient(100deg,#3FE0A8,#005043); -webkit-background-clip:text; -webkit-text-fill-color:transparent;
02 · Shiny Text Recomendado

Shiny Text · react-bits → vanilla

Base sólida legible + un brillo que barre. Nunca baja de contraste porque los dos stops son claros.

background:linear-gradient(110deg,#3FE0A8 42%,#e2fff3 50%,#3FE0A8 58%); background-size:220% 100%; -webkit-background-clip:text; -webkit-text-fill-color:transparent; animation:shine 3.4s linear infinite; /* @keyframes shine{to{background-position:-220% 0}} */
03 · Gradient Text

Gradient Text · react-bits → vanilla

Teal ↔ lime, ambos legibles. On-brand (usa tu Lime/300) y con más movimiento.

background:linear-gradient(90deg,#3FE0A8,#61FF61,#3FE0A8); background-size:200% auto; -webkit-background-clip:text; -webkit-text-fill-color:transparent; animation:slide 4.5s linear infinite; /* @keyframes slide{to{background-position:200% center}} */
04 · Sólido + glow

Sólido + glow

La opción más segura y silenciosa. Cero riesgo de contraste, brillo sutil al hover.

color:#3FE0A8; text-shadow:0 0 14px rgba(63,224,168,.35);
